# Ошибки и отчёты стража

Два канала в GlitchTip (формат Sentry envelope). Оба анонимные, оба включены по умолчанию
и выключаются отдельно: `-Dmebet.errors=false` и `-Dmebet.reports=false` (лаунчер передаёт
выбор игрока). DSN задаются в [`config/reporting.json`](../config/reporting.json); пустой
DSN — канал в этой сборке молчит. Решения стража от каналов не зависят: неизвестное
закрывается и окно причины показывается в любом случае.

## Что уходит

**Метки каждого события:** версия и вид сборки, архитектура, версия, сборка и редакция
Windows (или ядро Linux/macOS), клиент и Java, вендор и версия драйвера видеокарты, язык
системы, класс ВМ, Secure Boot и HVCI вкл/выкл, случайный id сеанса и секунды от старта.

**Карточка файла** (для каждого файла в событии): имя, обезличенный путь, класс папки,
доступна ли папка на запись, размер, SHA-256; архитектура PE, `TimeDateStamp`,
VERSIONINFO; результат проверки подписи, вид подписи (встроенная / каталог / нет), по
каждой подписи — CN, O, OU, C, серийник, SHA-256 листа, выпускающий CA, корень и его
класс, закреплённые корни, на ключе которых держится цепочка, EKU, срок действия, метка
времени; сработавшее правило.

**События:** закрытия (неизвестный модуль, денилист, прокси-DLL, лишний файл, чужой агент,
дев-режим, ВМ, чужой код в памяти, скрытый образ, внешний attach, отладчик, снятый хук),
инвентарь сторонних модулей (≤ 50 за сеанс), новый сертификат известного издателя,
очищенные переменные окружения, драйверы не от Microsoft, точки расширения ОС, чужой хук
поверх нашего, инжектированный ввод (раз в 30 минут и при выходе), прочее (время, Wine,
неизвестный гипервизор, классы, определённые во время работы).

## Что не уходит никогда

Ник, аккаунт, UUID игрока, имя компьютера и пользователя, MAC, HWID, серийники и UUID
SMBIOS, заголовки окон, список процессов (кроме родителя при отладчике), содержимое файлов
(только хэши), IP в теле события. Память — только из чужих исполняемых регионов и не
больше 256 байт.

## Обезличивание путей

`C:\Users\<имя>\…` → `%USERPROFILE%\…`, так же `%APPDATA%`, `%LOCALAPPDATA%`, `%TEMP%`,
`%ProgramFiles%`, `%ProgramData%`, `%WINDIR%`; папка игры → `%GAME%`, Java → `%JAVA%`;
любая другая папка пользователя → `<user>`.

## Объём

Не больше 100 событий за сеанс, событие ≤ 64 КБ, строки ≤ 512 символов, списки ≤ 50.
Отчёт о закрытии уходит сразу; клиент закрывается после отправки или через 3 секунды.
Без сети отчёт теряется: на диск страж ничего не пишет.

## Как отчёт превращается в запись списка

1. Задача «Closed: unknown module X (Y)» — посмотреть VERSIONINFO и подпись, SHA-256 на
   VirusTotal поиском по хэшу.
2. Честный подписанный софт → запись в `config/publishers.json` (CN + O + корень из
   карточки). Неподписанный честный → SHA-256 в собранный список, только если продукт понятен.
3. Чит → `config/denylist.json` (отпечаток листа или издатель + имя файла).
4. Пересборка и переподпись стража; задачу закрыть с версией релиза.
